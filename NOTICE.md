## BIDS schema (BEP032 draft)

`src/fairephys/_resources/bids/schema-bep032-508cfc7b.json` is the BIDS schema built from the BIDS specification with the draft extension for microelectrode electrophysiology (BEP032, bids-specification pull request #2307 at commit 508cfc7b). The BIDS validator checks the curated datasets against it.
